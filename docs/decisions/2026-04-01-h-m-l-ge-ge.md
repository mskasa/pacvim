# { } / H M L / ge gE コマンドをスコープ外とする

- Date: 2026-04-01
- Type: ADR
- Status: Active
- Author: masahiro.kasatani

## Context

PacVim は「遊びながら vim を学ぶ」ゲームであり、
実装するコマンドは実用頻度と学習価値で優先順位をつける必要がある。

## Decision

以下のコマンドを実装スコープ外とする。

- `{ }` ：段落間移動。PacVim のマップ設計との相性が悪く、対応ステージを作りにくい
- `H M L` ：画面内移動。実用頻度が低く、`gg/G` で代替できる
- `ge gE` ：前の単語末尾へ移動。実用頻度が低く、`b` で代替できる

## Consequences

- 実装・ステージ設計のリソースを `f/t` など実用頻度の高いコマンドに集中できる
- 将来的に追加したい場合は新たな ADR を作成して判断する
